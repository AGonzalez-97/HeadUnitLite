**Fecha:** 2026-11-12
**Estado:** Beta

### Novedades de esta versión

1. **El actualizador ya no se rompe por un texto pegado por error.**
   - Si en "Pegar token" quedaba guardado algo que no es un token (por ejemplo un informe copiado), el pedido a GitHub fallaba y la pantalla decía "Sin conexión a internet".
   - Ahora solo se guarda un token con forma válida; si lo copiado no lo es, avisa "Lo copiado no parece un token de GitHub". Un valor inválido ya guardado se ignora y se usa el token propio de la app.

2. **El registro de la app no guarda el valor de los encabezados de un pedido inválido.** Antes el texto del error podía incluir un token.
