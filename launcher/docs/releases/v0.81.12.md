# Onix Launcher v0.81.12

**Fecha:** 2026-11-11  
**Estado:** Beta

### Novedades de esta versión

1. **El lector OBD2 y los viajes ya no dependen de la pantalla.**
   - La conexión con el lector y el registro de viajes de Mi auto pasan a vivir con la aplicación. Si Android vuelve a crear la pantalla, el lector sigue conectado y el viaje sigue contando.
   - La forma de conectar y de reintentar no cambia.

2. **El actualizador reconoce una versión publicada de nuevo.**
   - Ajustes → Sistema compara también el número de compilación. Si una versión se corrige y se vuelve a publicar con el mismo número de versión, se ofrece igual.
   - El mensaje "Ya tenés la última versión" muestra la versión y la compilación instaladas.
