## Nuevo
- Pestaña Spotify con Listas, Recientes y Buscar; tocar algo lo reproduce en la radio (Premium, Spotify Connect) sin abrir Spotify.

## Cómo conectar
1. developer.spotify.com/dashboard → Create app → Redirect URI `onixlauncher://spotify`, Web API.
2. Copiar el Client ID (Settings).
3. En el launcher: pantalla de música → Spotify → pegar el Client ID → Conectar con Spotify → aceptar.
4. Abrir Spotify una vez en la radio para que aparezca como dispositivo.

## Seguridad
El Client ID y los tokens quedan solo en el equipo. No están en el código ni en GitHub.
