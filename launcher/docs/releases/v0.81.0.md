# Onix Launcher v0.81.0

**Fecha:** 2026-11-08

## Qué trae

- **Actualizador integrado en Ajustes → Sistema (`Updates` en `SettingsScreen.kt`):** permite pegar una sola vez un token de lectura de GitHub (`SharedPreferences("actualizaciones")`), consultar la última versión publicada en GitHub Releases, descargar `onix-launcher.apk`, comprobar que su certificado de firma coincida con el de la app instalada y abrir el instalador de Android con un toque (`FileProvider` + `REQUEST_INSTALL_PACKAGES`).
- **Botones Anterior (`⏮`) y Siguiente (`⏭`) en el mini-reproductor (`NavMusicScreen.kt`):** al minimizar el panel de música para ver el mapa a pantalla completa (`984 dp`), la píldora superior suma controles para retroceder y avanzar de canción (o de emisora de radio) además de `▶/❚❚` y `❮ Música`.
- **Reproducción de canciones en Recientes y Buscar de Spotify (`Spotify.kt`):** `SpotifyItem` guarda el `contextUri` del álbum del tema y `SpotifyApi.playBody` envía `{"context_uri":"spotify:album:...","offset":{"uri":"spotify:track:..."}}` para que Spotify Connect arranque la canción igual que cuando se elige una lista.
- **Spotify al dar contacto y al volver el Wi-Fi (`Media.kt`):** `LastAudio.resumeRadioAfterNetwork` retoma también Spotify cuando vuelve el Wi-Fi tras el arranque (en el informe `19-02` la red tardó 69 s en conectarse), `spotifyPlay` envía siempre el botón `KEYCODE_MEDIA_PLAY` además de `transportControls.play()`, y `IgnitionAudio.kickSpotify` refuerza el `play` a los `1500 ms` y `3200 ms` antes de volver al launcher.
- **OBD2 sincronizado con el arranque Bluetooth de la radio NWD (`Obd.kt`):** el estéreo reinicia su chip Bluetooth ~12 s después de `ACTION_MCU_STATE_CHANGE` `estado=1` (`18:57:45 rw.zlink.bt.name=Chevrolet`); ahora `ObdRecovery` espera `15 s` (`WAKE_SETTLE_MS`) tras el contacto antes de abrir canales RFCOMM, inicia por la manera 3 (`DEFAULT_PREFERRED_WAY = 2`, `createRfcommSocket(1)`), pausa los intentos con el contacto apagado (`estado=0`) y cierra también el `ParcelFileDescriptor` (`mPfd`) del socket Bluetooth.
