## Novedades
- **APK mucho más liviano:** antes incluía todo dos veces, para procesadores de 32 y de 64 bits. La radio del auto (Allwinner T3) es de 32 bits, así que la parte de 64 (unos 16 MB) nunca se usaba. Ahora el APK solo incluye lo que usa la radio. El tamaño exacto figura abajo, en "Resultado de la compilación".
- **Versiones publicadas más rápido:** GitHub hace los tests, el APK y las capturas al mismo tiempo, en lugar de uno detrás de otro. Los tests siguen siendo obligatorios: si alguno falla, no se publica.
- En la radio todo funciona igual.
- Este APK ya no se instala en celulares que son solo de 64 bits (algunos modelos de 2023 en adelante). La app está pensada para la radio.

## Cómo probarlo
Instalar sobre la versión anterior y verificar que todo funcione como antes (Inicio, mapa, radio, Android Auto). Guía: `docs/INSTRUCTIVO.md`.

## Migración
Se instala sobre la versión anterior, sin desinstalar.
