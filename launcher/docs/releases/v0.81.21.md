# Onix Launcher v0.81.21

**Fecha:** 2026-11-12
**Estado:** Beta

---

### Novedades de esta versión

Resultado de una revisión de todo el código propio buscando partes que, después de una falla, no vuelven a intentar solas.

1. **La app se da cuenta sola de que internet volvió.**
   - Antes solo pedía todo de nuevo cuando Android avisaba que la red se había cortado y vuelto. Con el Wi-Fi "conectado" pero sin internet, ese aviso nunca llegaba y el clima, las listas, la letra y la radio quedaban como estaban.
   - Ahora, cuando un servidor vuelve a contestar después de una caída, se pide todo de nuevo.

2. **La caída se detecta en segundos, no en minutos.**
   - Mientras no hay internet, la app prueba la red cada 30 segundos. Antes dependía de que alguna pantalla pidiera algo (con el clima ya cargado, podía tardar 15 minutos).

3. **La radio por internet se retoma sola.**
   - Si una emisora se corta por falta de internet, vuelve a sonar cuando la red regresa.

4. **Las listas de Spotify y la letra se cargan de nuevo al volver la red**, sin cambiar de pestaña.
