# repositorio ni a la app: los audios se generan una vez y quedan en assets/voz/inicio_<id>.ogg.
#
# id|voz|modelo|estabilidad|estilo|texto
#   voz: "biblioteca:<idioma>:<acento>:<género>[:<uso>[:<descripción>]]" busca en la biblioteca pública de ElevenLabs la voz
#        más usada con esos datos y la agrega a la cuenta; "propia:<nombre>" usa una voz de la cuenta
#        (las prediseñadas, como George o Daniel).
#   estabilidad 0–1 (más baja = más expresiva); estilo 0–1 (exageración del estilo).
#   Todas dicen solo el slogan de Chevrolet, "Find new roads." (pedido del autor, v0.72.0).
#   "diseno:<género>:<idioma>:<descripción>" crea una voz nueva con el diseño de voces de ElevenLabs
#   a partir de la descripción (v0.72.0): anda con el plan gratuito, que no deja usar la biblioteca
#   por la API (HTTP 402). Las voces diseñadas son nuevas: no imitan a ninguna persona.
#   "propia:<nombre>>…": si en la cuenta hay una voz con ese nombre (creada a mano en la web de
#   ElevenLabs con el diseño de voces, que en la web sí es gratis), se usa esa; si no, lo que sigue.
#   Pasos en docs/VOCES_IA.md.
#   "comercial": locutor de publicidad estadounidense de voz grave (estilo de comercial de autos).
